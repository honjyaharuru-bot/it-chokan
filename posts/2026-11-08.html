【続報】ドコモの流出は約29.5万件で確定、ahamoの受付サイトも止める

前回は「最大約30万件」の段階でした。第三報で、最大29万4839件（個人約20.4万・法人約9.1万）と内訳が出て、項目は氏名・生年月日・住所・電話番号・契約内容、一部で口座情報も含むと分かりました。

今回の攻撃は確認されていないものの、予防策として11/6 18時からahamoの新規受付サイトも停止。対象者へのSMS案内が始まり、見舞金も検討中です。

たとえると泥棒が入った家で、盗まれた物のリストが確定し、念のため勝手口まで閉めた段階です。

止まっているもの
ドコモオンラインショップ、My docomo、ahamo新規受付サイト（再開時期は未定）
専用窓口
0120-451-360

やることドコモを名乗るSMSやメールのリンクは踏まない。案内が来たら、公式サイトから自分でアクセスして確認しましょう。

注意

ロート製薬、約280万人分の個人情報が流出。通話録音とカード情報も

通販の顧客約280万人分の氏名・住所・電話番号などが流出しました。うち9715人はカード番号と有効期限、さらに電話受付の通話録音の一部も持ち出されています。

入口は電話システムのアカウント情報で、そこを足がかりに複数の顧客管理システムへ広がりました。セキュリティコードは含まれず、二次被害は今のところ確認されていないとしています。

たとえるとコールセンターの通用口の鍵で入った泥棒が、廊下伝いに顧客台帳の部屋を次々に開けていった形です。

やること通販を使った人はカード明細を確認。開発・運用側は、外部サービスのアカウントから社内の他システムへ横移動できないか見直しを。

ヤバい

QNAPのNAS、Plexの穴「Plex2Shell」経由で乗っ取りの報告

QNAPが11/6、NASに入れたPlex Media Serverの脆弱性（4件の連鎖）を突かれ、NASが侵害された報告を受けていると警告しました。NASのOS自体は対象外で、Plexアプリが入口です。

4件とも10月にKEV入り済み、つまり以前から攻撃に使われています。更新しても、すでに仕込まれた不正プログラムは消えません。

たとえると金庫そのものは頑丈でも、横に置いた「動画再生用の小窓」から手を入れられた状態です。

対象
QNAPのApp Centerから入れたPlex Media Server
CVE
CVE-2026-96652 / 96654 / 96655 / 96656
直った版
Plex Media Server 1.43.3.10861以降

やることPlexを更新し、外部公開（ポート32400）は閉じるかVPN経由に。公開していたなら侵害前提で、OSのクリーン再インストールとパスワード変更を。

#新技術

注目

政府がサイバー緊急対策、予備費約100億円で「救援隊」も

相次ぐ漏えいを受け、政府が11/6に緊急対策パッケージを決定しました。官民の専門家による「サイバー救援隊」が被害企業の初動を支え、経産省はAIを使う精鋭チームを11月末までに作ります。

能動的サイバー防御として攻撃者のサーバーへのアクセスも広げる方針。企業には、不要な個人情報の削除が求められています。

たとえると空き巣が続いた町で、消防団のような駆けつけ部隊をつくり、「使わない貴重品は家に置かないで」と回覧板を回した形です。

やること持っているだけの古い顧客データを棚卸しして削除。外に公開した管理画面や、委託先がつなぐVPNのMFAも点検を。

今日のキーワード

サプライチェーン攻撃：本丸ではなく、電話システムや委託先など「つながっている所」から入る攻撃。自社の鍵だけでなく、取引先に渡した合鍵の管理まで見るのが今どきの守り方です。
