【続報】N-centralの新たな穴、公開から数時間で悪用。最新の修正版も破られる

前号でお伝えしたIT業者向けの遠隔管理ツールN-centralで、新たな穴が11/12に公開され、数時間後に悪用が始まりました。最新の修正版の機器も含め、少なくとも21台が侵害されています。

新しい穴4EverAble2Shellは、古い連携機能Legacy APIが有効だと、ログインなしで最上位の管理者権限rootを奪えます。開発元のN-ableは修正版を準備中です。

たとえると合鍵庫を修理した翌日に、別の入口からこじ開けられた状態です。

新しい穴
4EverAble2Shell（CVE-2026-90436＋権限昇格の穴）、端末側を狙うAgent2Shell
被害
少なくとも21台（うち19台はHotfix 2適用済み）。攻撃は11/12 18時ごろ（日本時間）から
直った版
未公開（N-ableが準備中）
侵害の目印
見覚えのないサービス xvd.service、/tmp/.xvd や /var/tmp/.xvd のファイル

やること利用者: IT業者にPC管理を任せている会社は業者に確認。管理者: Legacy APIの無効を確かめ、自社に置くオンプレミス版は止めて侵害の目印を探す。

個人情報の漏えい公表まとめ（3件）

今日の漏えい公表は3件です。最大は無印良品で、カード番号の全桁など約109万件を暗号化せずに残していたと11/12の会見で説明しました。無印と宝くじ公式サイトでは、よそで漏れたパスワードを試すリスト型攻撃も疑われています。

  • 【続報】無印良品（良品計画、MUJI Card）約109万件2021年7月までの会員のカード番号全桁・生年月日など（有効なカードは約34.5万件）。使わなくなった番号を消さず、伏せ字も暗号化もせず保存
  • 宝くじ公式サイト（都道府県・指定都市が発売元、11/11公表）件数非公表氏名・住所、当落履歴、当せん金の受取口座（名義と番号の上4桁）を見られた恐れ。リスト型攻撃の可能性
  • サイバーセキュリティクラウド（企業向けWebセキュリティ）調査中一部顧客の企業名・氏名・メールアドレス、サービスの通信関連情報。社員の開発用GitHubの認証情報1件が流出し、第三者のアクセスを確認

たとえると合鍵を使い回し先で試されたうえ、もう使わない古い控えまで金庫に入れっぱなしだった状態です。

やること利用者: MUJI Cardの再発行を検討し、宝くじサイトと同じパスワードを他でも使っていれば変更。管理者: 使わなくなった個人情報が残っていないか棚卸しし、開発用の認証情報は期限付きに。

データ圧縮Brotliの穴「HTTP2Shell」、悪用確認済み。Node.jsやPythonも対象

Googleのデータ圧縮方式Brotliの穴「HTTP2Shell」について、国内の脆弱性情報サイトJVNが11/12に情報を更新しました。10月から悪用が確認されている穴で、多くのWebサーバーやアプリが部品として使っています。

細工した圧縮データを送られるだけで乗っ取られる恐れがあります。サーバー用の実行環境Node.jsや、プログラミング言語Pythonの部品も対象です。

たとえると荷ほどき係が箱の大きさを確かめずに中身を広げ、隣の棚の書類まで上書きしてしまう状態です。

CVE
CVE-2026-111497（CVSS 9.8、EPSS 82.6%）
直った版
Brotli 1.0.10 / 1.1.1 / 1.2.1、Node.js 22.23.4 / 24.22.1 / 26.12.1、Python brotli 1.2.1
KEV
10/27に掲載済み

やること管理者: Node.jsやPython、コンテナの中のBrotliの版を洗い出して更新。再起動だけでは古い部品が残るため、作り直して入れ替える。

Webサーバーの定番Apacheに、ログインなしで乗っ取れる穴。2.4.71で修正

Webサーバーソフトの定番Apache HTTP Server（Apache）に、ログインなしで乗っ取られる重大な穴が見つかり、11/11に修正版2.4.71が出ました。高速な通信方式HTTP/2を有効にしたサーバーが対象です。

実際の悪用はまだ報告されていません。ただ、米Red Hatは確実に動く攻撃手法が研究で示されたとしています。

たとえると高速レーンを開けている料金所だけ、ゲートを素通りできる抜け道が見つかった状態です。

CVE
CVE-2026-119618（CVSS 9.8、Red Hatの評価）
対象
2.4.55〜2.4.70でHTTP/2を有効にしている場合
直った版
Apache HTTP Server 2.4.71（RHELなどは各社の修正パッケージ。Debianの一部は未修正）
回避策
設定でHTTP/2を無効にし、HTTP/1.1だけにする

やること利用者: 自分でサーバーを運用していなければ対応不要。管理者: 2.4.71か各Linuxの修正版へ更新。すぐ無理なら、すべての仮想ホストでHTTP/2を止める。

ソフトバンクのホームルーター「Airターミナル6」に穴、修正は自動適用済み

ソフトバンクの置くだけWi-FiのホームルーターAirターミナル6に、機器の命令を勝手に実行される穴が公表されました。修正版はすでに自動で当たっており、利用者がすることは基本ありません。

悪用には管理画面へのログインが必要です。ソフトバンクは9月に機器を動かす内蔵ソフト（ファームウェア）の修正版を出し、自動で適用しています。

たとえると玄関の鍵を持つ人なら配電盤まで勝手にいじれる欠陥が、業者の巡回で知らないうちに直っていた状態です。

CVE
CVE-2026-101107（CVSS 3.0で8.0、4.0で8.6）
対象
ファームウェア v1.01.80以前
修正
2026年9月公開の版を自動適用（未接続の機器はつないだ時に適用）

やること利用者: 管理画面のパスワードを初期設定のままにしない。管理者: 事業所で使う機器があれば、管理画面でファームウェアの版を確認。

Amazon、AWSを手元で再現する「AWS Emulator」を無料公開。コードはすべてAIが記述

AmazonのクラウドAWSが、AWSの機能を手元のPCで無料で再現できるAWS Emulatorを公開しました。AWSのアカウントがなくても、アプリの動作を試せます。

AWSを操作する命令の受け口（API）をまねて作られ、数百のサービスに対応します。権限の判定は本物と違うため、セキュリティの試験には向きません。コードはすべてAIエージェントが書き、人の目では確認していないとしています。

たとえると本番の舞台を借りなくても、そっくりのセットで通し稽古ができるイメージです。

やること利用者: AWSで開発している人は、課金を気にせずテストに使える。管理者: 本物とずれる部分があるので、最終確認は本物のAWSで行うルールに。

今日のキーワード

リスト型攻撃：どこかで漏れたIDとパスワードの組を、別のサイトで片っ端から試す攻撃。今日は無印良品や宝くじ公式サイトで疑われています。サービスごとにパスワードを変えておけば、被害はそこで止まります。
