ヤバい

MS月例更新、Outlookの悪用中の穴をふさぐ。開くだけでログイン情報が漏れる恐れ

Microsoftが11/11未明（日本時間）に月例更新を公開し、メールソフトOutlookの悪用中の穴をふさぎました。細工したファイルを開くだけでWindowsのログイン情報が盗まれる恐れがあり、早めの更新が必要です。

ファイルを開くとOutlookが警告なしに攻撃者のサーバーへ接続し、Windowsの古いログイン認証方式NTLMで使うパスワードのハッシュ（元に戻せない形に変換した値）が送られます。解読されるとなりすましに使われます。今月は1,000件超を修正し、企業向けメールサーバーExchangeなどの緊急の穴も含みます。

たとえると封筒を開けただけで、家の合鍵の型を勝手に差出人へ送り返してしまうような状態です。

CVE
CVE-2026-124194（KEV掲載、11/10）
更新
Windows 11: KB5132061 / KB5131087、Windows 10（延長サポート）: KB5131096
KEV対応期限
11/24（米連邦機関向け）

やること利用者: Windows Updateを実行して再起動し、心当たりのない添付ファイルは開かない。管理者: 今月の更新を優先して配布し、外部への不要な通信を絞ってNTLMの利用を減らす。

Chromeに今年8件目の悪用中の穴、Googleが修正版

ブラウザのChromeで、すでに攻撃に使われている穴をGoogleが修正しました。今年8件目で、11/10に米政府の「悪用確認済みリスト」KEVにも入りました。Chromeの穴も悪用中なので、更新と再起動を。

データを書き表す書式XMLを処理する部分で、使い終わったメモリを再び使ってしまう「解放後使用」の不具合です。Chromeの元になるオープンソースのChromiumを土台にする、MicrosoftのブラウザEdgeなども、修正版が出しだい更新が必要です。

たとえると返却済みのロッカーが、前の利用者の鍵でまだ開いてしまうような状態です。

CVE
CVE-2026-125350
直った版
Chrome 157.0.8103.50以降（Windows/Macは .50/.51）
KEV対応期限
11/24（米連邦機関向け）

やること利用者: メニューの「ヘルプ→Google Chromeについて」で更新し、再起動。管理者: 社内PCのChromeとEdgeの版数を確認し、再起動していない端末に促す。

個人情報の漏えい公表まとめ（3件）

最大は簿記検定などで知られる日本商工会議所のネット試験で、最大98万人分の氏名や生年月日、点数が漏えいした恐れがあります。家電量販のエディオンはカード情報も。エディオンと商工会議所は、Webに不正なプログラムやファイルを仕込まれていました。

  • エディオン（家電量販、通販サイト）最大約1.37万人氏名・住所など、カード情報（最大556回分の入力）、ID・パスワード1,141人分、ギフトカード5,360枚。決済画面が改ざんされ不正プログラムを設置
  • 住友生命「Vitality」（健康増進型保険、NTTデータが受託運用、11/9公表）約8万人氏名・住所・電話・生年月日・メールのいずれか、約1,000人は一部を伏せたカード番号。申込システムに不正アクセス
  • 日本商工会議所（簿記などのネット試験）最大約98万人氏名・生年月日・性別・合否と点数、任意登録のメール・電話・住所。試験管理の外部サーバーに不正なファイルを設置

たとえるとお店のレジ横にこっそり盗み見カメラを置かれ、入力した内容がそのまま抜かれていた状態です。

やること利用者: エディオンの通販でカードを使った人は明細を確認し、同じパスワードを使い回していれば変更。商工会議所を名乗るメールやSMSのリンクは踏まない。管理者: Webサーバーの見覚えのないファイルと決済画面の改ざんを定期点検。

ヤバい

メール防御装置Barracuda ESGに、ログインなしで乗っ取れる穴が悪用中

企業のメールを検査する米Barracudaの装置Email Security Gateway（ESG）で、ログインなしで最上位の管理者権限（root）を奪える穴が悪用され、11/10にKEVへ入りました。使っている組織は急ぎ更新を。

パスワード変更処理で認証をすり抜ける穴と、時刻設定の処理でOSの命令を実行できる穴を組み合わせます。11/3の攻撃コード公開後、11/9に悪用が確認されました。管理画面を外部に公開していなければ狙われにくいとしています。

たとえると郵便検査の受付係の制服を合言葉なしで奪われ、郵便を好きにすり替えられる状態です。

CVE
CVE-2026-116606（CVSS 9.3）、CVE-2026-111560（CVSS 8.6）
直った版
ESG 9.4.0.030以降（自動更新を止めていれば手動適用）
KEV対応期限
11/13（米連邦機関向け）

やること管理者: ESGを9.4.0.030以降へ更新し、管理画面をインターネットから外す。公開していた場合は侵入の痕跡を確認。

Anthropic、Claudeが会議に参加して計画を作る「Claude Meetings」などを公開

米AIスタートアップのAnthropicが11/11未明（日本時間）、対話型AIのClaudeが会議に参加し、話しながら計画や予定表を作るClaude Meetingsをベータで公開しました。共同編集できる表計算とホワイトボードも有料プランで使えます。

Meetingsはビデオ会議のGoogle Meetに参加者として入り、終了後にメモややること一覧を残します。使えるのは当面、法人向けのTeam/Enterpriseプランだけです。社外に情報を渡さないよう、社外の人がいる会議には管理者が許可しない限り参加せず、途中で入ってきたら自動で退出します。社内データとつなぐClaude Dataは正式版になりました。

たとえると書記役のアシスタントが会議に同席し、話した端から議事録と工程表を書いてくれるイメージです。

やること利用者: AIを会議に入れる前に、参加者へひと声を。管理者: AIを会議に参加させるルールと、つなぐ社内データの範囲を先に決めましょう。
