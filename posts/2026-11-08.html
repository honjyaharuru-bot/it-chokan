注意

個人情報の漏えい公表まとめ（5件）

最大はロート製薬の約280万人で、カード情報と通話録音も含みます。今回は電話システムやメール配信の委託先など、本体以外の入口から入られた事案が目立ちます。

  • 【続報】NTTドコモ約29.5万件氏名・住所・契約内容、一部で口座情報。件数が確定し、ahamoの受付サイトも予防停止
  • ロート製薬約280万人氏名・住所など。うち9715人はカード番号と有効期限、通話録音の一部も。入口は電話システムのアカウント
  • ライフコーポレーション最大13.3万件ネットスーパー会員のメールアドレスなど。入口はメール配信の再委託先
  • ドトールコーヒー最大2.5万件通販会員の氏名・住所・電話番号など。入口は通販サイトの管理画面
  • スマートニュース約2,800件取引先担当者のメールアドレスなど。パスワードやカード情報は含まない

たとえると本社の正門は固めたのに、出入りの配送業者の合鍵から倉庫に入られている状態です。

やること利用者: 「お詫び」を装うメールやSMSのリンクは踏まず、カード明細を確認。管理者: 委託先の接続経路と、外部に公開している管理画面を棚卸しして、MFAを必須に。

ヤバい

セガ系のゲームセンター網「ALL.Net」、不正アクセスで1週間停止

ゲームセンターの機械をつなぐALL.Netと、カードで遊ぶ記録を管理するAimeが、11/1から止まったままです。原因は第三者の不正アクセスで、再開のめどは立っていません。

太鼓の達人やマリオカートなど、バンダイナムコ系の作品にも影響が広がっています。オフラインで動ける期限が切れ、止まる機械も出ています。

たとえると商店街の共通ポイントカードのセンターが止まり、加盟店のレジまで動かなくなった状態です。

止まっているもの
ALL.Net、Aime、SEGA ID ほか
次の報告
11/8 9:00（公式Xアカウント）

やること利用者: 公式の告知を待ち、SEGA IDなどで同じパスワードを他でも使っていれば変更を。管理者: 共通基盤が止まったときに各拠点がどこまで単独で動けるか、期限を確認しておきましょう。

ヤバい

QNAPのNAS、Plexの穴「Plex2Shell」経由で乗っ取りの報告

QNAPのNASに入れた動画配信アプリPlexの穴が突かれ、NASが乗っ取られた報告が出ています。Plexを外部公開している人は、侵害されている前提で確認が必要です。

4件の脆弱性の連鎖で、10月にKEV入り済み。NASのOS自体は対象外ですが、更新しても仕込まれた不正プログラムは消えません。

たとえると金庫そのものは頑丈でも、横に置いた「動画再生用の小窓」から手を入れられた状態です。

対象
QNAPのApp Centerから入れたPlex Media Server
CVE
CVE-2026-96652 / 96654 / 96655 / 96656
直った版
Plex Media Server 1.43.3.10861以降

やること利用者: Plexを更新し、外出先から見る設定は止めるかVPN経由に。管理者: 公開していた機器はOSのクリーンインストールとパスワード変更まで行う。

#新技術

注目

政府がサイバー緊急対策、予備費約100億円で「救援隊」も

相次ぐ漏えいを受け、政府が11/6に緊急対策を決めました。被害企業に専門家を送る「サイバー救援隊」をつくり、企業には不要な個人情報の削除を求めています。

経産省はAIを使う精鋭チームを11月末までに設置。能動的サイバー防御として、攻撃者のサーバーへのアクセスも広げる方針です。

たとえると空き巣が続いた町で、駆けつけ部隊をつくり、「使わない貴重品は家に置かないで」と回覧板を回した形です。

やること管理者: 持っているだけの古い顧客データを洗い出して削除。データは持たなければ漏れません。
